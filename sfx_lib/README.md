# Sound-effect library (NO MUSIC)

`mixkit/<id>.mp3`: recorded effects from mixkit.co (Mixkit Sound Effects Free License: free for commercial use in videos, no attribution; don't redistribute the files on their own). Only ids listed in `tools/sfx_samples.py` → `APPROVED` may be used: each was screened for musical/tonal content (narrow, sustained spectral peaks). Rejected as tonal: 772, 1109, 1468, 1799, 2299, 2925, 2933, 2934, 3005, 3135.
The `.wav` files are decoded automatically on first use and are not committed.
