# Final videos (original quality)

Each final video is stored here as one full MP4 file, untouched and uncompressed (via Git LFS, because the files are over 100 MB).

**Download:** open the video file on GitHub (for example `the-lost-imam/The_Lost_Imam_FINAL.mp4`) and click the **Download raw file** button (the ⬇ icon at the top right of the file view).

Each folder has a `SHA256` file with the checksum of the original.
